# 概要とスコープ

## 目的

Che vuoi? は、タスク管理ツールのチケットを起点として自律的に作業を進めるバッチシステムです。チケットの内容に応じて実装・調査・設計のいずれかの経路を選び、`claude -p` を実行単位とするパイプラインを回して、成果物（PR / 調査メモ / ADR）を生成し、結果をチケットへ反映します。

## 命名

- 正式名称は **Che vuoi?**
- パッケージ／リポジトリ名は `chevuoi`
- CLI コマンドは `vuoi`

上位の定期実行層（複数ループを束ねる側）は別ソフトの `borro` であり、本仕様の対象外です。`borro` が `vuoi run` を周期的に起動する関係にあります。

## やること

- 複数のタスクソース（初期は Trello のみ）からのチケット取得
- チケット種別に応じた経路（implement / investigate / design / trivial）の選択
- git worktree による作業隔離
- `claude -p` をノードとするパイプライン実行
- 決定的ゲート（テスト・lint・型チェック）による合否判定
- レビューループ（収束保証つき）
- 終端状態に応じたチケット更新
- 作業中に発見した副次タスクの起票

## やらないこと（Non-goals）

- ノードの並列実行（1ラン内は逐次。ラン間の並列は将来検討）
- PR の自動マージ（PR 作成で必ず人間ゲートを挟む）
- 自動起票カードの自動実行（Inbox 止まり。{doc}`proposals` 参照）
- ワークフローフレームワーク（LangGraph / Temporal 等）の導入
- Web UI

## 基本原則

仕様全体を貫く原則は次の2点です。

1. **フロー制御に LLM を使わない。** 「次に何をするか」「合格か不合格か」は必ず決定的なルールで判断します。LLM は所見・成果物・分類候補を出力するだけです。唯一の例外は入口の triage 1回で、それも候補を1つ返すだけです（{doc}`triage` 参照）。
2. **すべての実行は明示的な終端状態で終わる。** 「なんとなく止まった」状態を作りません（{doc}`outcomes` 参照）。
